## 2 tier VS 3 tier Architecture

### 2 tier architecture

In Two tier architecture there are basically two layers one layer is client layer where is number of users and another is database layer where our main data is present

**Advantages**

Main advantage of 2 tier architecture is that it is ease to use because of only two levels

**Disadvantages**

1.Security - it is because client can access the database directly without any intermediate layer which can be solved by using three tier architecture using business layer

2.Scalability - when the number of users or clients increase then number of requestes also increase on the database which may rise problems due to direct linkage of both layers


### 3 tier architecture

In Three tier architecture there are basically three layers one layer is client layer, another layer is business layer and the last layer is database layer

Here Business layer is also called Application layer which handles numeber of clients and solve the limitations of two tier architecture
