## Database system
It include basically two things one is database and another is DBMS

## Database 
It is basically a collection of related data

## DBMS
There are various operation like insertion deletion updation that performed on the data for manipulations all of this done by DBMS (database management system)

Some Examples of DBMS are :
1. SQL Server - Microsoft
2. oracle 9i, 11, 12c etc
3. My SQL
4. DB2
